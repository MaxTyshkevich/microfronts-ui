# Что проверяют тесты

Есть два уровня проверки. Vitest с браузерным провайдером Playwright проверяет компоненты и useFormField напрямую. Playwright Test открывает настоящий Storybook и проверяет то, что видит пользователь в Canvas и Docs.

## Запуск

```sh
npx playwright install chromium
npm test
npm run test:playwright
npm run test:playwright:report
```

Playwright Test запускает Storybook на порту 6007, если он ещё не запущен. При изменении .storybook/main.ts или плагинов полностью перезапустите сервер: обновления только React/CSS недостаточно для применения конфигурации.

## Сценарии Playwright Test

| Проверка           | Действия                                         | Ожидаемый результат                            |
| ------------------ | ------------------------------------------------ | ---------------------------------------------- |
| Input без формы    | Открыть Default                                  | Одно поле без Submit/Reset                     |
| Настоящий hover    | Навести мышь на Input и Button                   | Меняются граница поля и фон кнопки             |
| Закреплённый hover | Открыть Hovered без наведения                    | Стиль совпадает с настоящим hover              |
| Фокус              | Нажать Tab в Default, открыть Focused            | Видимый контур и корректный клавиатурный фокус |
| Ошибка             | Открыть Error                                    | Ошибка видна сразу и связана через ARIA        |
| Disabled           | Открыть Disabled, нажать Tab                     | Элемент отключён и пропускается                |
| Docs               | Открыть страницу документации                    | Состояния отличаются одновременно, без play    |
| Форма              | Отправить пустое поле, исправить email, сбросить | Валидация, отправка и reset работают           |

Сценарии состояний выполняются в светлой и тёмной темах. У каждого теста есть понятное название, а сложные сценарии разбиты на test.step: шаги видны в HTML-отчёте.

## Отчёт и диагностика

HTML-отчёт находится в playwright-report. При ошибке сохраняются screenshot и trace в test-results. Успешные проверки Input Docs также прикладывают скриншот страницы в отчёт. Эти файлы не входят в npm-пакет.

Сравнение CSS выполняется без анимаций перехода, чтобы не сравнивать промежуточный цвет. Тест не заменяет hover фиктивным событием: Playwright перемещает настоящий указатель. Закреплённые стили Docs проверяются отдельно.
