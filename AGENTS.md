# Правила ui-библиотеки

Это отдельный репозиторий библиотеки компонентов. Это не микрофронт и не приложение.

## Границы

- Здесь живут базовые UI-компоненты без бизнес-логики.
- Компоненты должны быть пригодны для использования в shell, catalog и cart.
- Нельзя добавлять сюда сценарии конкретного микрофронта, например `CatalogProductCard` или `CartCheckoutButton`.

## Команды

- `npm install` - установить зависимости библиотеки.
- `npm run dev` - запустить TypeScript watch.
- `npm run typecheck` - проверить TypeScript.
- `npm run build` - собрать `dist` для публикации.

## Публикация

В жизни библиотека публикуется в npm registry как версионируемый пакет. Приложения зависят от конкретной версии, например `@microfronts/ui@1.2.0`.
